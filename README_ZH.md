## ADB Disabler

[English](README.md)

- Magisk / KernelSU / APatch 通用
- 开机(重启)后关掉开发者选项  USB调试和OEM 解锁

## 安装

下载 `ADB-Disabler-1.0.0.zip`，在管理器里刷入重启

可与[Auto USB](https://github.com/Shuoh118/Auto-USB)搭配使用

| 管理器 | 版本要求 |
|---|---|
| Magisk | 20.4+ |
| KernelSU | 0.9.0+ |
| APatch | 10.7+ |

## 构建

```sh
python3 build.py
```
