## ADB Disabler

[English](README.md)

- Magisk / KernelSU / APatch 通用
- 开机自动禁用 开发者选项 / USB调试 / OEM 解锁

## 安装

下载 `ADB-Disabler-1.0.1.zip`，在管理器里刷入重启

| 管理器 | 版本要求 |
|---|---|
| Magisk | 20.4+ |
| KernelSU | 0.9.0+ |
| APatch | 10.7+ |

## 构建

```sh
python3 build.py
```
